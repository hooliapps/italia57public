# italia57public

Vidéos prêtes à publier, hébergées ici pour que l'outil de programmation (Metricool) puisse les récupérer par un lien public.

Ce dépôt est public : n'y mettre que des fichiers destinés à être publiés. Aucun code, aucune clé.

- `reels/` : reels promo des apps (1080 × 1920, MP4).
- `posts/` : photos et reels des posts voyage, un dossier par journée puis par post (métadonnées retirées).

Lien direct d'un fichier : `https://raw.githubusercontent.com/hooliapps/italia57public/main/reels/<nom>.mp4`
